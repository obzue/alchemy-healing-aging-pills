# alchemy-healing-aging-pills

An agent skill for formulating healing and anti-aging pills, synthesized from
the top longevity and alchemy skills on GitHub.

## Sources synthesized

1. [HermeticOrmus/magnum-opus-skills](https://github.com/HermeticOrmus/magnum-opus-skills)
   — seven-stage Magnum Opus transformation pipeline
2. [FreedomIntelligence/OpenClaw-Medical-Skills](https://github.com/FreedomIntelligence/OpenClaw-Medical-Skills)
   — cellular senescence agent, senolytics, SASP markers
3. [longevity-genie/longevity-skills](https://github.com/longevity-genie/longevity-skills)
   — aging research synthesis and evidence-weighted review
4. [pjt222/agent-almanac](https://github.com/pjt222/agent-almanac)
   — alchemist agent with meditate/heal checkpoints
5. [l-gevity/l-gevity-skills](https://github.com/l-gevity/l-gevity-skills)
   — A.L.C.H.E.M.Y. gate system for adaptive dispatch

## Install

```bash
npx skills add obzue/alchemy-healing-aging-pills
```

Or copy `SKILL.md` into your agent's skills directory:

- Claude Code: `~/.claude/skills/alchemy-healing-aging-pills/SKILL.md`
- Cursor: `~/.cursor/skills/alchemy-healing-aging-pills/SKILL.md`

## Usage

```
/alchemy-healing-aging-pills
Make me an anti-aging pill for cellular senescence.
```
